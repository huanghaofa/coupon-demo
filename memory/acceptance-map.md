# 验收映射

| 需求 | 验收标准 | 验证方式 |
|---|---|---|
| 单实例统计 | 主表每行唯一卡券实例 ID | DOM 和 Mock 数据检查 |
| 用户标识字段 | 实例和 E3S 提交记录只展示 VIN、手机号码、oneID 三列；不存在归属类型列或筛选项 | DOM 和 Mock 数据检查 |
| 商品适用性 | 订单商品逐项标记适用/不适用及原因；不适用商品不进入商城价、优惠、退款和网点价汇总 | 详情 DOM、Mock 数据和计算检查 |
| 核销渠道与来源 | 商城显示为线上核销，E3S 显示为线下核销；渠道和来源可分别筛选 | DOM、筛选交互和 Mock 数据检查 |
| 四项价格快照 | 报表与详情展示适用商品商城价、适用商品实际优惠、卡券面值、适用商品网点价及各自来源；商城不提供卡券面值 | DOM 和详情抽屉检查 |
| 退款重算 | 有效优惠等于优惠减退款扣减，实例不产生负数行 | 详情抽屉交互检查 |
| 金额冻结 | 订单不可退款后确定最终有效优惠和应结算金额 | 实例详情事件链检查 |
| E3S 最终结算 | 无人工勾选和批次入口；订单冻结后产生一条带唯一请求 ID 的提交记录 | DOM、导航和详情链路检查 |
| 卡券规则设置 | 原页面保留 CRUD 和导出；无结算渠道列和字段；新增/编辑时线上、线下配置同时可见；线上价格标准值提供四项并标明数据来源；已有核销规则禁止改删 | 规则页 DOM、CRUD 交互和 Mock 数据检查 |
| 运行时规则路由 | 页面明确展示实例核销渠道在结算执行时选择线上或线下配置 | 规则页路由图和实例详情检查 |
