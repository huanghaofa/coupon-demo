# 项目变更记录

## 2026-07-23 规则渠道运行时路由

- 规则列表删除“结算渠道”列，新增/编辑弹窗删除结算渠道选择字段。
- 每套规则固定同时维护线上和线下配置，不再根据渠道选择控制配置区域显隐。
- 规则页新增运行时路由说明：读取卡券实例核销渠道，线上选择线上配置，线下选择线下配置。
- 规则新增、编辑、删除、查询、导出及已核销锁定逻辑保持不变。

## 2026-07-23 商品适用性与用户字段精简

- 商城商品明细新增“适用/不适用”和适用性原因；不适用商品保留用于核对，但不进入价格、优惠、退款或结算基数汇总。
- 实例详情新增“订单共 N 件、适用 M 件”说明及适用性列，不适用商品灰显。
- 报表金额列统一改为适用商品口径，并展示适用商品数量比例。
- 实例报表、详情和 E3S 提交记录删除“归属类型”表达，只保留 VIN、手机号码、oneID。

## 2026-07-23 核销来源与价格快照补充

- 实例报表新增核销渠道和核销来源，商城样例映射为线上核销，E3S 样例映射为线下核销。
- 新增商城商品单价、实际优惠金额、卡券面值、网点价、价格标准和结算基数列；卡券面值标记为卡券中心读取，其余线上数据标记为商城传入。
- 实例详情新增四项价格快照和来源，突出当前规则选中的结算价格标准，并以该金额展示计算公式。
- 规则新增/编辑弹窗沿用原页面能力，在四个线上价格标准选项旁直接标记数据来源。
