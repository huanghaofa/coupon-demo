# 项目记忆

## 项目定位

- 项目名称：商城卡券结算原型
- 创建日期：2026-07-22
- 类型：无构建步骤的静态前端原型
- 入口：`index.html`

## 产品目标

补齐商城渠道卡券的实例级结算、退款重算、金额冻结和 E3S 最终结算能力。

## 目标用户

卡券运营、结算管理人员、财务审计人员。

## 核心页面列表

- 商城卡券实例结算报表。
- 卡券实例详情抽屉。
- E3S 订单级提交记录。
- 卡券规则设置原页面扩展（查询、新增、编辑、删除、导出；隐藏结算渠道；同时维护线上和线下配置；结算时按实例核销渠道自动路由）。

## 核心用户路径

- 查询实例 → 追溯优惠和退款 → 等待不可退款 → 冻结订单最终金额 → 自动提交一次 E3S。

## 主要数据对象

- 卡券实例、结算归属对象（VIN 或手机号 + oneID）、订单商品优惠明细、退款明细、原有结算规则及商城金额来源调整、E3S 订单级提交记录。

## 交付方式

可本地打开和点击演示的无构建静态 HTML 原型。

## 已确认假设

- 本次不引入账期。
- 只有订单不可退款后才可冻结最终金额。
- E3S 提交发生在订单冻结且所有金额计算完成之后，每次订单冻结提交一次。
- 车辆级结算使用 VIN；用户级结算同时使用手机号和 oneID。

## 目录结构

- `js/components/` — 可复用的 B 端公共组件（如高级搜索、弹窗、分页器）
- `js/pages/` — 具体的业务页面逻辑（如仪表盘、线索列表）
- `assets/css/global.css` — 全局 B 端设计规范与通用组件样式
- `assets/css/app.css` — 应用基础样式与布局
- `config/nav.json` — 菜单路由配置（唯一路由数据源，由 `js/nav.js` 动态渲染）
- `mock/data.js` — 全站 B 端模拟数据集与状态机
- `SKILL-evolve-b-prototype.md` — B 端原型迭代演进技能，可供 AI Agent 在后续开发中调用
- `tools/` — 开发辅助工具脚本

## 工作原则

- 先理解现有代码和业务逻辑，再修改。
- 非必要不修改现有板块内容。
- 业务、Mock、文档、记忆和标注工具分别维护。
